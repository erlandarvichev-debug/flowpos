## Стало

- **Снимок цен заказа:** строка без цены — по действующим прайс-листам и скидкам на дату заказа (склад заказа); нет
  цены — `PRICE_MISSING`. Ставка НДС строки фиксируется явно (товара или стандартная на дату). Источник цен (прайс-лист,
  скидка, базовая цена) — в реквизитах заказа и на экране.
- **Реализация по заказу:** склад и покупатель — заказа (`ORDER_STORE`, `BASIS_COUNTERPARTY`); цены, скидка, НДС —
  **из заказа** (из запроса не принимаются); товар — только из заказа (`BASIS_PRODUCT`). При проведении — не больше
  остатка заказа (`ORDER_OVERSHIP`) под блокировкой заказа: параллельные отгрузки идут по очереди. Резерв заказа
  расходуется (FP-032).
- **Закрыть остаток заказа** — с причиной: резерв снимается, новых отгрузок/резервов нет, заказ не меняется
  (`ORDER_CLOSED`), «Исполнение» показывает «закрыт» и остаток.
- **Возврат по основанию:** только по проведённой реализации/чеку (`RETURN_BASIS_REQUIRED`, `BASE_NOT_POSTED`), покупатель
  и цены — из неё, склад по умолчанию — склад реализации (можно другой своей организации); при проведении — не больше
  отгруженного за вычетом прежних возвратов (`RETURN_EXCEEDS_SHIPPED`). Возврат без основания — явно, с причиной.
  Реализация показывает «Возвраты»: отгружено / возвращено / можно вернуть.
- **Себестоимость возврата — из исходной отгрузки** (себестоимость единицы продажи по этому документу и товару),
  детерминированно при пересчёте; без основания — по средней склада, как раньше.
- **Партии возврата — те, что отгружали:** одна — подставляется, несколько — «создать на основании» раскладывает по
  партиям (за вычетом уже возвращённого), чужая партия — `RETURN_LOT_NOT_SHIPPED`.
- Розничный возврат — по чеку тем же правилом.

## Не сделано / ограничения

- Скидка из прайса переводится в процент строки (до сотых) — сумма строки может отличаться от расчёта кассы на тиын.
- Изменить цену в отгрузке по заказу нельзя (только через изменение заказа); согласованное отклонение цены — нет.
- Закрытый заказ не переоткрывается.
- Возврат денег покупателю (платёж) и корректировочный ЭСФ — существующими механизмами (FP-036, ЭСФ), без
  автоматического создания.
- Счёт на оплату (INVOICE_OUT) в цепочку не входит.
