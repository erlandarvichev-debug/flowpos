# Платформа: три направления и «Супервайзер» — что сделано (20.11.2026)

Не выложено на flowpos.kz. Выкладка — только по слову владельца (меняет рабочую базу).

## Три направления (подписки)
- `trade` «Учётная система», `accounting` «Бухгалтерия», `supervisor` «Супервайзер» (`apps/api/src/modules/platform/subscriptions.ts`).
- У организации без строки подписки `trade` и `accounting` включены (так работали все до подписок), `supervisor` — выключен.
- Приостановка `trade`/`accounting` пока только скрывает разделы в меню (`AppLayout.vue`: `showTrade`, `showAcc`); адреса API не закрыты.
- Администратор платформы — таблица `platform_admins` (служебная, RLS только системный режим), назначается
  `node deploy/scripts/platform-admin.mjs --email … [--remove|--list]`. Раздел сайта «Платформа» (`/platform`).
- Роль организации `supervisor` (права `field.read`, `field.manage`) видит только «Торговые».

## «Супервайзер»
- API: `/field/*` (сайт, JWT + OrgGuard + подписка), `/field/agent/*` (телефон, заголовок `X-Device-Token`).
- Привязка телефона: код 6 цифр, 15 минут, один раз (хэш в `field_bind_codes`); попыток привязки — не больше 10 в минуту.
- «На точке / удалённо» решает сервер (`field-logic.ts`: радиус точки или 100 м; точность хуже 500 м — «не определено»).
- Фото: JPEG/PNG/WebP по сигнатуре, до 2 МБ, файлы в `FIELD_DATA_DIR` (в бою `/opt/flowpos/shared/data/field`),
  удаляются через 180 дней (раз в сутки, `FIELD_CLEANUP=0` — выключить).
- Сайт: «Торговые» — День на карте (Leaflet + OpenStreetMap), Посещения, Маршруты, Задания, План и факт, Точки, Представители.
- Рекламная страница `/welcome` (гость на `/` попадает туда). Контакты внизу — константа `CONTACTS` в `LandingView.vue` (пустые).
