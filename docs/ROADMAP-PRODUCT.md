# FlowPOS — план до уровня МойСклада (обход 23.11.2026)

Обход кода по трём разделам (каталог и контрагенты; продажи, закупки, деньги; склад, розница, отчёты, общее).
Главный вывод: учётное ядро сильное (журнал движений, FIFO/средняя, партии и сроки, резервы, ячейки,
двухэтапные перемещения, ЭСФ, автопилот), а интерфейс местами отстал: часть пунктов меню ведёт на старые
экраны `views/trade/*`, `views/pos/*`, `views/analytics/*`, которые читают поля, которых в API больше нет.

Размер: S — до дня, M — 1–3 дня, L — больше 3 дней.
