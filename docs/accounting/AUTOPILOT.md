# Автопилот: какие проводки формируются (для проверки бухгалтером)

Статус: **реализовано и покрыто тестами, ТРЕБУЕТ ПРОВЕРКИ БУХГАЛТЕРОМ.** Счета по умолчанию — `apps/api/src/modules/accounting/autopilot/accounts.ts`; переопределяются в учётной политике (`params.accounts`). Правила — `autopilot/trade-rules.ts` (версия `TRADE_RULE_VERSION`), денежные документы — `core/rules/money-rules.ts`.

## Как работает
- Торговый документ FlowPOS (из бухгалтерии, кассы, 1С или МойСклада) в статусе «Проведён» → запись движений `TRADE_DOCUMENT` + складские движения.
- Из бухгалтерии — синхронно, в одной транзакции с проведением: ошибка (нет остатка, закрыт период) отменяет проведение целиком.
- Из кассы и обмена — фоновый сверщик каждые 15 с (`ACC_AUTOPILOT_INTERVAL_MS`). Ошибка не мешает торговле: пишется «проблема автопилота» с причиной и подсказкой; исправление документа снимает проблему.
- Отключение: учётная политика `params.autopilot.enabled = false`; пропуск документов, учтённых в 1С: `params.autopilot.skipOwners = ["C1"]`.
- Снятие проведения / пометка на удаление → проводки отменяются (история сохраняется), себестоимость пересчитывается.

## НДС
- Плательщик НДС — из учётной политики на дату документа. Неплательщик: НДС не выделяется, входящий НДС включается в стоимость.
- Ставка: ставка строки → ставка номенклатуры → стандартная ставка на дату (`vat_rates`: 12% до 31.12.2025, 16% с 01.01.2026 — `verified=false`).
- Цены по умолчанию **с НДС** (`vatIncluded`): НДС = сумма × r / (100 + r), округление до тиына по строке.

## Себестоимость
- Метод — из учётной политики на дату движения: FIFO или средняя (по складу).
- Пересчёт детерминированный: по каждому товару вся история; порядок — дата, приходы раньше расходов в один день, время записи. Повторный пересчёт без изменений не создаёт записей (закрытие воспроизводимо).
- Документ задним числом автоматически пересчитывает себестоимость последующих расходов; прежние записи сохраняются как `SUPERSEDED`. Если затронут закрытый период — операция отклоняется (или требует переопределения с аудитом).
- Отрицательные остатки запрещены (`NEGATIVE_STOCK` с товаром, складом, датой и документом). Если политика разрешает — расход без партии получает нулевую стоимость до прихода (**упрощение, ПБ**).

## Известные упрощения (этап 3)
- Налоговый учёт (NU) по автопилоту пока не формируется (равен BU); налоговые разницы — этап 4.
- Зачёт авансов рассчитывается на момент проведения; при изменении более ранних платежей задним числом зачёт не пересматривается автоматически — проверка в мастере закрытия месяца (этап 3).
- Продажа с нулевой себестоимостью (разрешённый минус) не списывает количество в учёте до прихода.
- Документы обмена без организации берут организацию склада; без склада — проблема автопилота.
