# Реестр нормативных источников (Республика Казахстан) для бухгалтерского модуля FlowPOS

- Дата проверки всех пунктов: **2026-10-18**
- Метод: веб-поиск и чтение страниц (WebSearch/WebFetch), выгрузка текста приказа №185 с cdb.kz, прямой запрос к WSDL ИС ЭСФ.
- **Ограничение:** adilet.zan.kz (новая SPA, API требует токен) и gov.kz (SPA, API закрыт) автоматически прочитать не удалось. Поэтому большинство пунктов подтверждены **вторичными** источниками (cdb.kz, pro1c.kz, uchet.kz, mybuh.kz и др.), которые перепечатывают текст НПА. Перед боевым использованием ставки и сроки нужно сверить с текстом на adilet.zan.kz.

Как читать уровень уверенности:
- **ОФ**: подтверждено официальным источником (сам ресурс госоргана или живой госсервис).
- **ВТ**: подтверждено вторичным источником (правовая база или профильное издание, которое цитирует НПА).
- **НП**: не подтверждено, есть противоречие или нужна сверка бухгалтером.

### Субсчета 3211 / 3212 / 3213

**В Типовом плане счетов (приказ № 185) их нет.** В подразделе 3200 есть только 3210, 3220, 3230, 3240, 3250. Пятизначные и иные субсчета (3211 «СО», 3212 «ООСМС», 3213 «ВОСМС» и т. п.) организации вводят сами в **рабочем плане счетов** в рамках учётной политики. Так делают, например, типовые конфигурации 1С. Это **практика, а не норма**. Расшифровку 3211–3213 в FlowPOS нужно хранить как настраиваемые субсчета рабочего плана. Уверенность: **ВТ**.

Дополнительно: для ОПВР в типовом плане есть отдельный счёт **3250** «Обязательства по обязательным пенсионным взносам работодателя». ОПВ работника по описанию в приказе относится к **3220**.

Формула для FlowPOS (2026, ТОО на ОУР, без льгот):
```
ОПВ   = min(Начисл, 50*МЗП) * 10%
ВОСМС = min(Начисл, 20*МЗП) * 2%
ИПН   = max(0, Начисл - ОПВ - ВОСМС - 30*МРП) * 10%   (15% с годового превышения 8500 МРП)
ОПВР  = clamp(Начисл, 1*МЗП, 50*МЗП) * 3.5%            (не для родившихся до 01.01.1975)
СО    = clamp(Начисл - ОПВ, 1*МЗП, 7*МЗП) * 5%
ООСМС = min(Начисл, 40*МЗП) * 3%
СН    = max(Начисл - ОПВ - ВОСМС, 14*МРП) * 6%           (СО НЕ вычитается)
```
Порядок применения корректировок ИПН (10%/15% и годовой лимит вычета) должен проверить бухгалтер.

## Неподтверждённое / требует проверки бухгалтером

1. **Минимальный объект СН = 14 МРП (60 550 ₸).** Источники: pro1c.kz и uppersetup.com. Раньше минимальным объектом была 1 МЗП. Нужно сверить ст. 556–558 нового НК на adilet.zan.kz.
2. **Пониженная ставка НДС 5%:** один источник говорит «только 2026 год, с 2027 года 10%», другой «2026–2027». Нужно сверить ст. 503 НК. Ставку 0% отдельно не проверял.
3. **Ограничения зачёта НДС** (доля, пропорция, требование оплаты поставщику): в пределах прочитанного не найдены. Нужен полный текст ст. 480–486 НК.
