Статусы: **П** — запланировано · **Р** — реализовано · **✔** — проверено автотестом/сквозным сценарием · **ВД** — требует внешнего доступа · **ПБ** — требует проверки бухгалтером.

**Процент готовности этапа** = доля строк этапа со статусом ✔ (без учёта ПБ-оговорок). Считается по этой таблице, а не на глаз.
