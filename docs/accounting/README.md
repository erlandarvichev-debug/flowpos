# VPNet Accounting (бухгалтерский контур FlowPOS)

> Рабочее название задаётся одной константой `PRODUCT_NAME` во фронтенде и строкой в Swagger — меняется без правки логики.

FlowPOS — единая система VPNet: торговля, склад, касса (аналог МойСклада) + бухгалтерский и налоговый учёт Казахстана (по основным сценариям — аналог 1С:Бухгалтерии для Казахстана) + кадры и зарплата (аналог ЗУП). Бухгалтерия работает «на автопилоте»: документы торговли и кассы сами формируют проводки и НДС по версионируемым правилам, бухгалтер проверяет и закрывает период.

**Честный статус:** текущая версия — **система с базовым бухгалтерским контуром (этапы 1–2: ядро + автопилот торговли, склад, банк/касса)**. Она не является полной заменой 1С и не предназначена для официальной сдачи отчётности, пока сценарии и нормативы не проверены (см. [FEATURE_MATRIX.md](FEATURE_MATRIX.md)).

## Границы первой версии (этап 1)
- организации (ТОО/ИП), несколько организаций у пользователя, роли и права по организации;
- версионируемый план счетов РК, субсчета организации, аналитики (до 11 видов), количественный и валютный учёт;
- раздельный бухгалтерский (BU) и налоговый (NU) учёт в одной проводке-записи;
- документы: ручная операция, ввод начальных остатков, сторно; черновик → проведение → отмена/перепроведение;
- блокировка периода с переопределением по праву и причине, аудит;
- отчёты: ОСВ, карточка счёта, журнал проводок с расшифровкой до документа;
- справочники учёта: валюты и курсы, банковские счета, кассы, статьи, проекты, ставки НДС с периодами, учётная политика с датой начала.
