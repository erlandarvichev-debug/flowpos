# План этапов

Каждый этап даёт запускаемую версию со сквозным сценарием и тестами. Статусы функций — в FEATURE_MATRIX.md.

| Этап | Содержание | Сквозной сценарий этапа |
|---|---|---|
| **1** ✅ в работе | архитектура, организации, доступ, справочники учёта, бухгалтерское ядро, ОСВ/карточка/журнал, UI раздела | создать организацию → ввести остатки → ручные операции → изменить/сторнировать → закрыть период → сверить ОСВ |
| **2** | автопилот: поступление/реализация/возвраты из торговли FlowPOS и ручной ввод, склад (остатки по складам, партии, FEFO-подбор отдельно от оценки), банк и касса (ПКО/РКО, выписки с предпросмотром и защитой от повтора, сопоставление оплат), НДС к начислению/зачёту, авансы, мульти-организационность торговых справочников | купить товар → оплатить → продать часть → получить оплату → возврат |
| **3** ✅ 81 % | взаиморасчёты по договорам/документам, себестоимость FIFO/средняя с пересчётом задним числом, мастер закрытия месяца, валютная переоценка, финрезультат, баланс/ОПиУ/ДДС, экспорт XLSX/PDF | закрыть месяц → сверить ОСВ, склад, деньги, прибыль; повторное закрытие воспроизводимо |
| **4** | налоги (регистры, 300.00, 200.00, 910.00, 100.00 — только после проверки источников), ОС и НМА, зарплата и кадры (HRMS: bitemporal-история, налоги 2026, МТ102, проводки, взаимозачёт смен, табель из отметок) | начислить зарплату → удержать налоги → МТ102 → проводки → 200.00 |
| **5** | ЭСФ/СНТ/виртуальный склад (контракт адаптера + фикстуры, реальное подключение — при доступе к тестовой среде), адаптеры 1С/МойСклад/Битрикс24/reKassa/Wazzup/банки/CSV-XLSX/webhooks, мастер переноса из 1С | перенос остатков из выгрузки 1С → сверка ОСВ |
| **6** | производство, ИИ-помощник ru/kk, **MCP-сервер** (по решению владельца поднят в приоритете — сразу после ядра), подписки и тарифы, расширенная аналитика | ИИ создаёт черновик по тексту → человек проверяет и проводит |

## Порядок внутри работы
1. ядро и инварианты (этап 1) — готово, покрыто интеграционными тестами;
2. MCP-слой над сервисами ядра (чтение + черновики) — следующий шаг по запросу владельца;
3. этап 2 — автопилот торговли и НДС.
